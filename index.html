Claude Code Starter Kit

Every trick from our lessons on one page: what it fixes and the exact command. Tap any command to copy it. New lessons get added here.

Set up once

  1. 01

    CLAUDE.md — project rules

    Explaining your project in every new chat?

    • /init — Claude drafts it for you: stack, what not to touch, how to run tests
    • edit with /memory or by hand
    • for every project: ~/.claude/CLAUDE.md; personal rules: CLAUDE.local.md
  2. 02

    Skills

    Explaining the same thing to AI every time?

    • a skill = a folder with a SKILL.md: name, when to use it, instructions
    • Claude opens the right one itself, or call it: /skill-name
    • easiest start: tell Claude Make a skill from this chat
  3. 03

    Plugins

    Why do all Claude sites look the same?

    • /plugin → Discover tab → search frontend-design → Install for you
    • ask for the site again — no more template look
    • Claude Desktop: + next to the prompt box → Plugins → Add plugin
  4. 04

    MCP — connect your apps

    Claude can't see your calendar, Notion, email?

    • Claude Desktop / claude.ai: Settings → Connectors → Add custom connector
    • Claude Code: claude mcp add --transport http notion https://mcp.notion.com/mcp
  5. 05

    Learning mode

    Can't explain your own code?

    • /output-style → Learning
    • Claude explains every step and leaves a TODO(human) for you to write
    • Claude Desktop: "outputStyle": "Learning" in .claude/settings.local.json

Every session

  1. 06

    Plan mode

    Asked for a button — it rewrote half your app?

    • Shift+Tab until ⏸ plan mode on
    • Claude reads the project, proposes a plan, changes nothing until you approve
    • Claude Desktop: mode selector next to Send → Plan
  2. 07

    Context: /context, /compact, /clear

    Claude forgets what you agreed on by the end of a long chat?

    • /context — see what's eating the space
    • /compact keep the db schema — squeeze history, protect what matters
    • /clear — a clean chat for a new task

    Rule of thumb: /clear between tasks, /compact inside one.

  3. 08

    /goal — make it finish

    Claude said “done” — half the site is missing?

    • /goal the form submits and all tests pass
    • after every turn a fast model checks the condition; not met — Claude keeps going
    • /goal clear to remove it
  4. 09

    /rewind — undo

    Fixed one button, broke the site?

    • Esc Esc or /rewind → pick the prompt where it broke → Restore code
    • checkpoints last about 30 days

    Can't undo terminal commands (rm, mv) or your manual edits — keep git for those.

  5. 10

    Bring back an old chat

    Rebooted and yesterday's chat is gone? It's not.

    • claude -c — continue the last chat in this folder
    • /resume — pick any past chat
    • /rename cart & checkout — so it's easy to find later

Let it work on its own

  1. 11

    Auto mode

    Hitting “yes” 30 times?

    • Shift+Tab until ⏵⏵ auto mode on
    • safe stuff runs itself; risky stuff (rm -rf, force push) gets checked and blocked
    • needs Opus 4.6+ or Sonnet 4.6+; tune it in /permissions
  2. 12

    Sandbox

    Scared to leave Claude alone?

    • /sandbox — commands stay inside the project folder
    • a strange site — it asks first
    • macOS, Linux, WSL2
  3. 13

    Claude in the cloud

    Left a task overnight, closed the laptop — nothing done?

    • claude.ai/code → pick your GitHub repo → type the task
    • or from the terminal: claude --cloud "task"
    • by morning: a branch and a pull request. Pro, Max, Team
  4. 14

    Routines — on a schedule

    Checking your site and leads every morning?

    • Claude app: Code → Routines → New routine → Local
    • tell it what to check, set Daily 9:00 AM

    Runs while your laptop's on and the Claude app is open.

  5. 15

    Claude tests your site in Chrome

    “Done” — but the button doesn't work?

    • claude --chrome + the Claude in Chrome extension
    • open localhost:3000, click Book now, check the console
    • always on: /chrome → Enabled by default. Pro, Max, Team, Enterprise
  6. 16

    Hooks — a ping when Claude needs you

    Went for tea — Claude waited 10 minutes for your “yes”?

    • ask Claude: add a hook that pings my phone when you need permission
    • it writes the hook into ~/.claude/settings.json; /hooks shows what's set up
    • no hook: /remote-control + the Claude app, then /config → Push when actions required

A new trick every day — follow so you don't miss it.
